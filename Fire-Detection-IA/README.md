# Fire Detection AI

In this folder, you will find all our work about the IA Fire Detection Systeme.

Here a summary of the directory:

- [./Data-Sheet](./Data-Sheet) : Datasheet of the hardware component of the project
- [./model_final](./model_final) : Directory where all version of IA are grouped
- [./Script-IA](./Script-IA) : Directory which contain python script to run the IA on the Jetson Nano.
